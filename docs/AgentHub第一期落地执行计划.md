# AgentHub 第一期开发落地执行计划

版本：v1.0  
时间范围：2026-05-21 至 2026-05-31  
用途：飞书任务流执行版，不是架构讨论版

## 1. 目标

第一期只做一条完整主链路，并在 2026-05-31 前冻结：

```text
用户创建 dev 工作区
→ 进入 IM 式聊天
→ 选择或自建 Agent
→ Orchestrator 拆解并分派任务
→ Agent 在云端 workspace 修改代码
→ 前端看到 Diff / 预览 / 文件 / 文档 / PPT / 图片等产物
→ 用户打开预览 URL 或下载源码 zip
```

第一期完成后，6 月只做：

- bug 修复
- 演示优化
- 文档和视频
- P2 项目

## 2. 第一期开口范围

### 2.1 必做

```text
1. 只做 dev 类型工作区
2. 支持工作区创建、复用、切换
3. 支持 IM 式对话列表
4. 支持单聊模式和群聊模式
5. 支持 Agent 作为联系人展示
6. 支持用户自建 Agent
7. 接入至少 2 个主流 Agent 平台，优先 Claude Code + Codex
8. Orchestrator 支持串行、并行、失败降级、冲突处理
9. 支持聊天历史、pin 消息、项目摘要作为长期上下文
10. 支持产物内联展示：代码、Diff、文件附件、网页、文档、PPT、图片
11. 支持在线预览 URL
12. 支持源码 zip 下载
13. 支持一键应用 Diff / 基础代码二次编辑
14. 支持云端 Workspace Runtime、git worktree、构建日志
```

### 2.2 不做

```text
1. 桌面端
2. 移动端
3. 静态站点部署平台
4. 容器化部署平台
5. 完整版本历史
6. 深度局部修改编辑器
7. research / writing / chat 这些非 dev 工作区
8. Local Connector
9. GitHub OAuth 和仓库推送
```

### 2.3 P2

```text
1. 完整版本历史
2. 局部修改编辑器的高级能力
3. desktop / mobile
4. 非 dev 工作区模板
5. 完整部署平台
6. GitHub 导入和推送
```

## 5. 模块拆解

### 5.1 产品 / 前端

要做的事：

- 工作区首页
- 工作区列表
- 聊天页面
- Agent 联系人列表
- 产物卡片
- Diff 预览
- 预览弹窗
- 用户自建 Agent 表单

验收标准：

- 页面能按工作区组织
- 能看见聊天、Agent、产物三块
- 核心按钮能点通

### 5.2 后端 / 数据层

要做的事：

- Workspace / Conversation / Message / AgentRun / Artifact / ChangeSet 建模
- 会话读写
- 任务写入
- 产物写入
- 状态流转
- 审计日志

验收标准：

- 数据能完整落库
- 前后端字段稳定
- 能从数据库还原工作区状态

### 5.3 Orchestrator

要做的事：

- 识别用户意图
- 决定单聊还是群聊
- 决定串行还是并行
- 给每个 Agent 生成任务包
- 汇总结果
- 失败时降级
- 冲突时回退或提示

验收标准：

- 不是只会“转发消息”
- 能真正拆任务、派任务、收结果

### 5.4 Adapter Layer

要做的事：

- Claude Code Adapter
- Codex Adapter
- 统一输入输出格式
- 统一运行日志
- 统一超时和错误处理

验收标准：

- 至少 2 个平台都能跑
- 平台差异不暴露给业务层

### 5.5 Runtime

要做的事：

- 创建 workspace 目录
- 初始化 git repo
- 运行构建命令
- 生成预览 URL
- 生成 zip
- 支持 worktree
- 保留命令日志

验收标准：

- Agent 的改动都能落到 workspace
- 能产出预览和 zip

### 5.6 自建 Agent

要做的事：

- 新建 Agent
- 改名字
- 改 System Prompt
- 改工具权限
- 选择默认模型 / provider
- 保存成工作区可用 Agent

验收标准：

- 用户创建的新 Agent 可以立刻出现在联系人列表里
- 可以在聊天中直接点选或 @ 到它

## 7. 风险控制

### 7.1 先砍什么

如果进度不够，先砍：

- 额外 workspace 类型
- 深度版本历史
- 高级局部修改编辑器
- 完整部署平台
- 桌面端 / 移动端

不要砍：

- dev workspace
- 聊天主链路
- 自建 Agent
- Orchestrator
- 预览 URL
- zip 导出

### 7.2 最高风险点

1. Orchestrator 的并行和冲突处理
2. Codex Adapter 接入稳定性
3. 预览链路和构建产物生成
4. 自建 Agent 的权限模型
5. 聊天流里的产物卡片展示
