# 业务后端接口文档补充（2026-06-04）

本补充文档只记录本次文档预览链路的行为更新。

## `/api/projects/:projectId/files/preview`

当前返回结构统一为：

```json
{
  "kind": "docx",
  "path": "docs/report.docx",
  "name": "report.docx",
  "byteLength": 12345,
  "updatedAt": "2026-06-01T10:00:00.000Z",
  "sourceUrl": "/preview/runtime/proj-xxx/docs/report.docx",
  "summary": "DOCX 文件使用前端渲染预览。"
}
```

字段说明：

- `kind`: `pdf | docx | pptx`
- `sourceUrl`: 原文件运行时访问地址，供前端直接加载
- `summary`: 当前预览方式说明

## 当前预览策略

- `pdf`：继续使用浏览器原生 iframe 预览
- `docx`：前端使用 `docx-preview` 在浏览器内渲染
- `pptx`：前端使用 `@aiden0z/pptx-renderer` 在浏览器内渲染

## 约束说明

- 当前实现不依赖服务端安装 Office、LibreOffice 或其他桌面转换组件
- 更适合云服务器部署
- 单文件预览大小限制仍为 16MB
